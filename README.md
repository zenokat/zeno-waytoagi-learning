# zeno-waytoagi

Zeno 开发的非官方 WaytoAGI 知识库 Skill，让你的 Agent 按需查找和阅读社区资料。

## 三个主要功能

| 功能 | 能帮你做什么 |
| --- | --- |
| 按日期看更新 | 获取近期或历史更新，保留标题、原摘要和原文链接；支持从 2025-06-01 起。 |
| 搜索知识库 | 围绕你的问题查找 AI 教程、实践玩法与社区经验。 |
| 阅读文章 | 打开选中的文章或章节，取得正文供 Agent 继续整理。 |

资料来自 WaytoAGI，具体总结、推荐和判断由你的 Agent 根据任务完成。

## Quickstart

把下面这段话直接甩给支持 Skill 的 Agent：

```text
帮我安装并配置这个 Skill：
https://github.com/zenokat/zeno-waytoagi/tree/main/skills/zeno-waytoagi

请读取 Skill 内的 setup.md，检查环境、准备依赖、完成飞书配置，并验证三个主要功能。需要我授权时，请告诉我具体怎么操作。
```

Agent 会自行安装完整 Skill，并参考 [setup.md](skills/zeno-waytoagi/setup.md) 完成配置。已有飞书应用和授权可以复用；需要你配合时，优先通过官方链接或二维码在浏览器完成操作。

当前版本仍在本地打磨，尚未上传 GitHub。现在验收时，把本地仓库目录交给 Agent；上述 GitHub 安装入口在发布后可用。

## 使用案例

### 1. 看近期或历史更新

```text
看看 WaytoAGI 最近更新了什么，给我标题、原摘要和原文链接。
```

最近更新按当天或前一天查询，并注明实际日期。历史更新也可以直接问：

```text
看看 WaytoAGI 2025 年 12 月 31 日更新了什么，保留原摘要和链接。
```

支持从 2025-06-01 起更新日志已列出的日期；来源未列出指定日期时，Agent 会明确说明。

### 2. 搜索知识库

```text
在 WaytoAGI 知识库里找 ComfyUI 入门教程，先给我相关条目和链接。
```

先看搜索结果，再让 Agent 展开你感兴趣的文章。

### 3. 阅读文章

```text
帮我阅读这篇 WaytoAGI 文章，并整理其中的操作步骤：<粘贴文章链接>
```

也可以只要求读取某个章节。正文中的图片、视频或外链未读取时，Agent 会说明范围。
