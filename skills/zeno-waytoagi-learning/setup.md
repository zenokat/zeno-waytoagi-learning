# 安装与配置

由你完成安装、配置与验证，只在需要授权、安全输入或用户选择时请用户参与。

## 准备

- 将仓库中的 `skills/zeno-waytoagi-learning/` 完整安装到当前 Agent 的 Skill 目录，保全目标位置已有的用户修改。
- 准备 Python 3.9 以上（可用 `Asia/Singapore` 时区）和官方 [lark-cli](https://github.com/larksuite/cli/blob/main/README.zh.md)。

## 飞书接入与用户交互

应用配置、用户授权或 CLI 报错时，先运行 `lark-cli skills read lark-shared`，按其中的触发索引读取对应配置、身份与权限指南，并结合相关命令的 `--help` 处理。具体流程及通用故障恢复遵循 CLI 当前版本的说明。

优先复用已有可用配置与授权；全程沿用同一配置，读取使用用户身份，保留其他配置及全局默认项。

需要用户参与时：

- 需要接入应用时，优先由你发起官方一键配置，将官方链接与二维码交给用户在浏览器配合。说明为什么需要、用户要做什么，完成后由你接续；只有该路径实际受阻时才说明原因并引导终端或手动输入。
- 密钥通过官方 CLI 安全输入，不要求发到聊天；凭证、授权链接与临时代码不写入 Skill 或 Git。
- 只申请读取所需权限；已有权限足够就继续，仅不足时协调用户补充。遇到资源访问资格问题时，说明需要用户核对的条件，不通过反复登录或新建应用解决。

## 验证三个功能

按 [SKILL.md](SKILL.md) 实际执行：

- 按日期看更新：传入明确的 `--date`，返回 `status=ok` 和非空条目，记录查询日期及条目数，不要求来源当天更新。
- 知识库搜索：用“ComfyUI”等主题验证，确认 `ok=true` 和实际结果，记录结果数量与分页状态。
- 正文读取：读取本次搜索命中的一篇文章，确认 `ok=true` 和非空正文；导航页继续选择相关文章，说明节选及未展开媒体的范围。
