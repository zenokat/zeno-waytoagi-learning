# 扩展读取

按日期看更新、搜索和正文读取直接按 SKILL.md 执行；需要翻页、标题筛选、时间范围检索或局部正文时查阅本文。沿用当前飞书配置，命名配置的调用继续携带同一 `--profile`。

## 扩展搜索

- 翻页：响应的 `has_more=true` 表示还有结果；保留原关键词、知识库和筛选条件，追加返回的 `--page-token`。按任务需要继续，不用第一页推断全库总量。
- 后续页失败、令牌重复或没有新增结果时，按[失败处理](failures.md)处理；恢复后仍无法继续就停止，保留已取得条目并注明仅有部分结果，不无限翻页。
- 只查标题：追加 `--only-title`。
- 展示结果：去掉标题与摘要中的高亮标签，保留实际 URL。元数据时间为 0 时按未提供处理；目录、快捷方式和文章不能混作独立教程数量，搜索结果也不提供热门排行依据。

## 时间范围检索

用户要找“近三个月的 Skills 教程”等资料时，以**社区更新日志的收录日期**确定时间范围，再从原标题和原摘要筛选主题候选。单日请求如“昨天更新了什么”直接使用日期脚本。

1. 按 `Asia/Singapore` 将相对时间换算成明确的起止日期；“近三个月”按日历月回溯，并在回答中注明本次范围。
2. 从包内日期脚本使用的更新入口和归档来源出发，读取目录，沿页面实际年份链接定位涉及的年度。年份取自来源标题或年份路由。
3. 完整读取年度日志，并按[局部正文](#局部正文)的方法定位入口的近期更新章节、补齐尚未归档的日期。年度正文使用：

   ```bash
   lark-cli docs +fetch --doc "实际年度归档链接" --as user --doc-format xml --detail full
   ```

   本步完成条件是：年度日志正文与近期更新章节均已读取，并记录两者最新的可确认日期；目录用于定位，正文用于主题筛选。检查 `ok=true`、正文、日期标题及完整性提示；有 `tips`、`excerpt` 或结构无法确认时，按[失败处理](failures.md)交付实际已取得范围。较大页面可先按月份或日期目录分章读取，保留本次实际覆盖的日志日期。
4. 只保留起止日期内的日志批次，在内存中按标题和原摘要匹配主题词，例如 `Skill`、`Skills`、`技能`；按任务筛选相关候选，按需读正文核实具体做法。年度与近期日志重叠时，按日期与实际文章链接去重，优先保留近期版本。
5. 按日志日期由新到旧返回标题、用途或原摘要和链接，并说明筛选口径与实际覆盖范围。日志主题命中是候选资料，不等于全库文章总量或热度排行；来源未列出的日期保持为未观察。

文档创建时间、个人编辑时间和搜索结果中为 0 的时间字段，不用来代替社区日志日期。

## 局部正文

按章节读取时，先获取目录与实际块 ID：

```bash
lark-cli docs +fetch --doc "文章链接" --as user --scope outline --detail with-ids
lark-cli docs +fetch --doc "文章链接" --as user --scope section --start-block-id "返回的章节块ID" --doc-format markdown --detail simple
```

按关键词取得上下文：

```bash
lark-cli docs +fetch --doc "文章链接" --as user --scope keyword --keyword "关键词" --doc-format markdown --detail simple
```

关键词结果或 `<excerpt>` 是局部内容，不等于整节或全文。上下文不足时，从目录定位相关章节，再按该章节的实际块 ID 读取；出现 `tips` 时说明限制。保留本次来源、范围与引用，媒体及独立表格未读取时明确标记。
