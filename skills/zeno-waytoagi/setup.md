# 安装与配置

由你完成安装、配置与验证，只在需要授权、安全输入或用户选择时请用户参与。

## 准备

- 将仓库中的 `skills/zeno-waytoagi/` 完整安装到当前 Agent 的 Skill 目录，保全目标位置已有的用户修改。
- 准备 Python 3.9 以上（可用 `Asia/Singapore` 时区）和官方 [lark-cli](https://github.com/larksuite/cli/blob/main/README.zh.md)。

## 飞书接入与用户交互

依据 CLI 的帮助与自带说明，自行完成应用配置和用户授权，优先复用已有可用配置。全程沿用同一配置，读取使用用户身份，保留其他配置及全局默认项。

需要用户参与时：

- 提供官方操作链接，说明为什么需要、用户要做什么，并请其完成后回复确认。先交还控制权，确认后由你接续执行。
- 密钥通过官方 CLI 安全输入，不要求发到聊天；凭证、授权链接与临时代码不写入 Skill 或 Git。
- 只申请读取所需权限。遇到资源访问资格问题时，说明需要用户核对的条件，不通过反复登录或新建应用解决。

## 验证三个功能

按 [SKILL.md](SKILL.md) 实际执行：

- 最近更新：返回 `status=ok` 和非空条目，记录实际批次日期及条目数，不要求来源当天更新。
- 知识库搜索：用“ComfyUI”等主题验证，确认 `ok=true` 和实际结果，记录结果数量与分页状态。
- 正文读取：读取本次搜索命中的一篇文章，确认 `ok=true` 和非空正文；导航页继续选择相关文章，说明节选及未展开媒体的范围。

## 交付结果

简要告知安装位置、使用的飞书配置和三项验证结果，并给出所读文章的标题与原文链接。

未通过时按[失败处理](references/failures.md)诊断并说明实际阻碍、已完成的部分和下一步所需操作；复用已有环境时如实说明，未执行的安装或首次授权不写成已经完成。
