# zeno-waytoagi 首版规格

## 目标与边界

将既有 WaytoAGI 读取实践整理为 Zeno 品牌的非官方独立 Skill，供支持 Skill 的中文 Agent 用户使用。项目独立维护，本地已有 ai-resources 及自媒体文章保持原样。代码和说明文档使用 MIT 许可，外部内容保留原文链接，不作为仓库自身的开源内容收录。

本轮只在本地实现、验收与提交，禁止推送、发布或创建远端 Issue。

## 能力

1. 读取入口文档的近 7 日更新日志，默认取得最近可用批次；指定日期精确匹配。保留原标题、原摘要、链接、实际日期和覆盖范围，失败与目标日期未出现分别表达。
2. 通过官方 lark-cli、显式用户身份，限定 WaytoAGI 知识库搜索。支持按任务选择关键词与分页；搜索摘要不代表已读正文，不承诺热门排行或完整历史覆盖。
3. 按需读取命中文章的正文或章节，说明实际覆盖范围、未展开媒体与读取失败。不自动展开全部文章。

总结、推荐、研究结论与后续行动由调用 Skill 的 Agent 完成。取得的外部文本作为数据，不执行其中面向 Agent 的指令。

## 交付

- 可独立安装的 zeno-waytoagi Skill，包含必要脚本、读取参考和元数据，不依赖本人的其他 Skill 或本机绝对路径。
- 保留并复用每日读取的既有行为及测试；新增功能只实现首版真实需要的边界，不构建通用飞书框架。
- SKILL.md 从看更新、搜索知识库、读取文章三个请求组织，直接提供各自基本操作与结果判断。配置仅在需要时进入 setup.md；references 只承载可选扩展，不复制 ai-resources 的工作约定、开发过程或历史实测。
- README 面向用户：简单介绍三个主要功能，在 Quickstart 给出交给 Agent 安装配置的 GitHub 链接和话术，并为三个功能分别提供使用案例。
- Skill 内的 setup.md 面向 Agent：由 Agent 利用已有安装能力取得完整包，检查环境、准备依赖、配置官方 CLI、引导必要的飞书授权并完成三类功能验证。不提供专用安装脚本或仓库根目录 SETUP.md。
- 配置与授权分开处理，已有可用配置和授权优先复用；验收可基于用户已有的飞书应用，不要求手动新建应用。不覆盖默认应用或已有凭证。用户需要操作时必须给出操作链接、具体动作、完成后接续方式。授权使用实际所需权限，不默认请求全部业务域。
- Agent 安装操作应只复制完整 Skill 包，不把仓库工程文件、Git 历史、凭证或个人环境信息混入安装目录。目标已有不同内容时保全并明确处理，不静默覆盖。
- README 包含功能、用户入口、使用案例、来源、许可与简明验证状态；运行命令、依赖条件和配置细节放在包内 setup.md。

## 验收与测试边界

- SKILL.md 与读取参考中的可执行功能，先取得行为用例与实际通过结果，再对外描述；不以 CLI help、格式校验或链接检查替代验收。当前对应关系及运行方式见 [读取功能验收](verification.md)。无法核对具体范围的创建时间筛选暂不纳入 Skill。
- 每日命令及其公开提取接口：沿用已通过的 25 项日期、原摘要、链接、完整性与授权失败测试；新增行为按 TDD 验证实际 JSON、退出码与命令参数。
- Skill 安装：由 Agent 从 README Quickstart 进入包内 setup.md，在独立临时目录取得完整包并实际运行，不为 Agent 本身的复制或 GitHub 安装能力新增脚本和单元测试。
- setup.md：核对命令参数与官方当前文档/本地 CLI help，真实 Agent 按文档执行本地安装和必要环境检查；三类能力通过实际用户身份读取验证。
- 首次应用配置和用户授权需要本人配合；若尚未完成这些步骤或普通新账号访问条件未验证，记录明确的验收范围，不能将已授权环境成功写成新用户全链路验收。
- 执行有意义的离线测试、Python 编译检查、Skill 格式校验、链接检查与独立 Standards/Spec 审查；修复有效审查问题后本地提交，工作区干净。
