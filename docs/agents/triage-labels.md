# Triage Labels

将工程技能中的五个分流角色映射到本仓库的 GitHub 标签。

| 技能角色 | 仓库标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者判断 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格完整，可交给 Agent 实施 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不安排处理 |

技能提到某个分流角色时，使用表中的仓库标签。
