# 读取功能验收

Skill 中的可执行读取路径必须有对应的用例并实际通过。CLI 帮助、文档格式和链接检查不能替代行为验证。新增参数组合应先补用例，验证实际内容与范围，再写入 Skill。

完整产品覆盖结论另见[逐项承诺核对](coverage-audit.md)：下表证明的是已列读取路径，不能据此宣称 setup 与所有 Agent 恢复、交付约定均已验收。

## 运行方式

从仓库根目录运行离线测试：

```bash
python3 -m unittest discover -s tests -v
```

默认执行 50 个离线用例（49个产品行为、1个测试隔离守卫），跳过 16 个 CLI/快照联网检查及 22 个 Agent 检查。后者包括21个合成场景测试方法与1个真实 setup 方法；分页方法含3个不同场景。跳过不等于验收通过。

在可访问系统钥匙串、已有有效飞书授权的环境中，单独运行联网验收：

```bash
WAYTOAGI_LIVE=1 python3 -m unittest discover -s tests -p '*live.py' -v
```

需要指定已有配置时，同一命令再设置 `WAYTOAGI_PROFILE=<配置名>`。测试只读，不登录、不创建应用、不保存响应正文或凭证；没有可用账号、网络失败或来源变化都会报失败，需要核对后重验。

Agent 场景的隔离、运行入口与证据边界见 [Agent 行为测试](agent-testing.md)。它们实际启动被测进程，检查调用和交付，不因文档包含某个词就算通过。
